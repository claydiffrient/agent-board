Agent Board

===

The idea is that this is a native Mac app that manages work for AI agents, primarily Claude Code.


There should be a few primary screens:
  - Orchestrator Commmand
  - Task Board
  - Status
  - Notes


## Orchestrator Command
  - This screen runs an instance of Claude Code and allows me to communicate with it.
  - The orchestrator can spin up additional instances of Claude Code and assign work to them.

## Task Board
  - Visually shows tickets that have been created and their current status
  - Shows what agent has been assigned to work on what

## Status
  - Shows the roster of agents and their current tasks

## Notes
  - Shows durable memories that agents can refer to and that I can view
